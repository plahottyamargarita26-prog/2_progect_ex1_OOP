# MyMatrix

A C# project that implements a `MyMatrix` class for working with rectangular matrices of double values.

## Features
- Multiple constructors for creating matrices from different data types.
- Matrix dimensions using `Height` and `Width` properties.
- Accessing and modifying elements using an indexer and getter/setter methods.
- Matrix addition (`+`) and multiplication (`*`).
- Matrix transposition and transposed copies.
- Formatted matrix output using `ToString()`.

## Project Structure
- `Program.cs` – demonstrates the class functionality.
- `MatrixData.cs` – matrix storage, constructors, properties, and element access.
- `MatrixOperations.cs` – matrix operations and transposition.

## Technologies
- C#
- .NET
